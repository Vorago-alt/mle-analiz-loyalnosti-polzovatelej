# Анализ данных Яндекс Афиши

Учебный проект: анализ заказов Яндекс Афиши за первый месяц продаж.

## Состав проекта

- `main.py` — точка входа: загрузка данных, обработка и вывод результатов
- `src/processing.py` — класс `DataProcessor`: загрузка и предобработка данных
- `data_export.ipynb` — выгрузка исходных данных из БД через SQL
- `data/orders.csv` — результат выгрузки (создаётся ноутбуком)
