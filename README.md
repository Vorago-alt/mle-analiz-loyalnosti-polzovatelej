# Анализ данных Яндекс Афиши

Учебный проект: анализ заказов Яндекс Афиши за первый месяц продаж.

## Состав проекта

- **main.py** — точка входа: загрузка данных, обработка и вывод результатов;
- **src/processing.py** — класс DataProcessor: загрузка и предобработка данных;
- **data_export.ipynb** — выгрузка исходных данных из БД через SQL;
- **data/orders.csv** — результат выгрузки (создаётся ноутбуком; папка data/ в репозиторий не входит).

2. Создать виртуальное окружение и установить зависимости:

4. Запустить проект одной командой: python3 main.py

## Итоги анализа

Анализ охватывает 21 622 пользователя и 287 746 заказов за первый месяц продаж (после чистки данных).

**Ключевые цифры:**
- средняя выручка с заказа — 545,34 руб.;
- доля вернувшихся (2+ заказа) — 61,3%.

**Что показал разрез по первому заказу:**
- desktop-пользователи возвращаются чаще mobile: 63,8% против 60,8% — при том, что mobile даёт 83% пользователей;
- лучший жанр — выставки (64,2% возврата) и театр (63,4%), основной сегмент — концерты (44% пользователей, 61,8% возврата);
- самые «возвращающиеся» крупные регионы: Каменевский (67,3% возврата при 33% пользователей) и Североярская область (63,8%).

**Проверка гипотез:**
- «спорт возвращает чаще концертов» — **не подтвердилась**: возврат спорта ниже (55,8% против 61,8%), 95% ДИ разности [-9,97%; -2,68%];
- «крупные регионы возвращают чаще» — **не подтвердилась**: связь размера региона с возвратом слабая (корреляция Спирмена ~0,09).

**Корреляционный анализ:**
- на число покупок сильнее всего влияют поведенческие признаки: средний интервал между заказами (phi_k ~0,43) и средний чек (~0,28);
- признаки первого заказа (жанр, устройство, день недели, регион) значимого влияния не дают — поведение после первого контакта важнее «точки входа».

## Рекомендации для Яндекс Афиши

1. **Улучшить мобильный путь повторной покупки.** Mobile — основной канал (83% пользователей), но с худшим возвратом (60,8%). Точки роста: напоминания и пуш-уведомления о повторных событиях, упрощение повторной покупки в один клик.
2. **Догонять покупателей после дешёвого первого заказа.** Средний чек связан с числом покупок — стоит предлагать подборки и промокоды на более дорогие события после первого касания.
3. **Локальные кампании в регионах с низким возвратом** (например, Озернинский край — 55,3%, Малиновоярский округ — 56,0%).
4. **Брать в модель прогноза возврата поведенческие признаки** (частота заказов, средний чек), а не только параметры первого заказа — они объясняют поведение лучше.
